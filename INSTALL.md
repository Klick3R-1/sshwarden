# Installation

## Prerequisites

- Python 3.11+
- `pipx` (`pacman -S python-pipx`)
- Bitwarden CLI at `/usr/local/bin/bw` (download from bitwarden.com/help/cli)
- Bitwarden desktop app with SSH agent enabled

## 1. Install the package

```bash
pipx install /path/to/k-sshkey-solution
# or directly from git:
# pipx install git+https://github.com/youruser/k-sshkey-solution
```

This installs two binaries to `~/.local/bin/`:
- `sshkey-ui` — web dashboard
- `sshkey-sync` — CLI sync (regenerates `~/.ssh/bwpub/` and `bwpub.auto.conf`)

To upgrade after pulling changes:
```bash
cd /path/to/k-sshkey-solution
git pull
pipx reinstall sshkey-ui
systemctl --user restart sshkey-ui
```

## 2. SSH config

Add the following includes to `~/.ssh/config` (order matters — local overrides must come first):

```
Include ~/.ssh/config.d/bwpub-local.conf
Include ~/.ssh/config.d/bwpub.auto.conf
```

Create the config directory if it doesn't exist:
```bash
mkdir -p ~/.ssh/config.d
```

`bwpub.auto.conf` is generated by `sshkey-sync`. `bwpub-local.conf` is managed by the web UI for local key overrides.

## 3. Bitwarden SSH agent socket

The service expects the Bitwarden SSH agent at `~/.bitwarden-ssh-agent.sock`. Confirm it exists when the desktop app is running:
```bash
ls -la ~/.bitwarden-ssh-agent.sock
```

If your socket path differs, edit `sshkey-ui.service` before installing.

## 4. Local hostname

Add a hosts entry and allow unprivileged processes to bind to port 80:

```bash
# resolve http://sshkeys to localhost
echo '127.0.0.1 sshkeys' | sudo tee -a /etc/hosts

# allow user services to bind to port 80
echo 'net.ipv4.ip_unprivileged_port_start=80' | sudo tee /etc/sysctl.d/80-unprivileged-ports.conf
sudo sysctl -p /etc/sysctl.d/80-unprivileged-ports.conf
```

## 5. systemd user service

```bash
mkdir -p ~/.config/systemd/user
cp sshkey-ui.service ~/.config/systemd/user/
systemctl --user daemon-reload
systemctl --user enable --now sshkey-ui
systemctl --user status sshkey-ui
```

The UI is available at **http://sshkeys** (or **http://localhost** if you skipped step 4).

## 6. First run

1. Open http://sshkeys — you will be prompted for your Bitwarden master password.
2. Click **Sync** to generate `~/.ssh/bwpub/` and `~/.ssh/config.d/bwpub.auto.conf`.
3. Existing items using the old name convention will show a **migrate** badge — use the inline form to migrate them to structured custom fields.

## Uninstall

```bash
systemctl --user disable --now sshkey-ui
rm ~/.config/systemd/user/sshkey-ui.service
pipx uninstall sshkey-ui
rm -rf ~/.config/sshkey-ui   # stored session
```
